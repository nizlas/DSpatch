# orders-kit

The shop's order records, customers and ledger.

- `src/orders.js` loads the order records from `data/orders.json`.
- `src/customers.js` looks up customers.
- `src/ledger.js` holds the ledger's figures.
- `src/format.js` formats amounts for people.
- Amounts are in öre (hundredths of a krona).

Run the tests with `npm test`.

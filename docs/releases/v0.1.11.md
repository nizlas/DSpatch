# DSpatch 0.1.11

A Linux-only pre-release from the latest main, so the current review and code-walk work can be installed on Debian or Ubuntu x64. It carries no Windows installer and no Windows host package: the Windows work (DSP-182) is still open, and v0.1.10 remains the latest Windows pre-release.

## Since 0.1.9 (the last Linux release that was not a pre-release)

- **Explanation profiles made consistent (DSP-181).** The chooser offers Essentials, Standard and Teacher, named in the window's language; Standard is the default when no profile was chosen before. All three rest on the same facts, code references and findings and share one typography in Step and Discussion; they differ in manner and depth. The base text before *Show more* names the concrete functions, settings and defaults; *Show more* complements it instead of repeating it. Original is kept as a legacy presentation, so older explanations stay readable; nothing saved is renamed or deleted.
- A profile chosen before a walk is prepared writes every step's explanation in that profile, and such a walk is read without further calls. A failed explanation waits for *Try again* rather than being asked again on its own, and only the window that shows the panel asks for a step's explanation.
- **Build identity (DSP-182).** The build identity is now computed from sources with normalised line endings, so client and host built from one commit on different machines carry the same identity. On Linux this changes nothing you see; it is why a client and its bundled host no longer read as different builds on Windows.

## Install or upgrade

Install `dspatch_0.1.11_amd64.deb` on Debian or Ubuntu x64 (`sudo apt install ./dspatch_0.1.11_amd64.deb`). Installing over an earlier version keeps `~/.config/DSpatch`: conversations, reviews, profile choices, zoom and settings.

The host that an earlier version started keeps running through the upgrade. 0.1.11 speaks the same contract as 0.1.8–0.1.10, so the new window connects to it and says that a restart is needed to finish updating; press **Restart host** there. A host on a machine you connect to over SSH is updated the same way, from the same release's host package.

`dspatch-host-0.1.11-<commit>-linux-x64.tar.gz`, `host-manifest.json` and `SHA256SUMS` are published with this release. There is no Windows host package in it, so a 0.1.11 client cannot install a host on a Windows machine over SSH.

## Verification

What was tried before and after publication, and with what, is recorded in DSP-183. All trials used isolated profiles, a throwaway neutral project and the simulated provider; no real provider sign-in or model call.

Not established in this release:

- Windows: no Windows artifacts are published here; DSP-182 keeps the Windows installer's open points (the uninstaller under Bitdefender, the window trials on Windows).
- Real-provider explanation quality (simulated provider only).
- Distributions other than Ubuntu and Debian, and arm64.

# DSpatch 0.1.25

A Linux-only pre-release with DSpatch's new app icon (DSP-204): the blue–turquoise interlaced DS with a glowing sphere in the middle, on a dark rounded plate. It replaces the green "D" and Electron's generic icon. Nothing else in DSpatch's behaviour changes. No Windows installer or Windows host package is published; the Windows work (DSP-182) is still open.

## Where the icon is

- **The application launcher.** The `.deb` installs the icon at 16–512 pixels in the hicolor theme, and the desktop entry uses it.
- **The dock, the taskbar and the window switcher.** Every DSpatch window carries the icon itself: the main window, review, walk, the discussion's own window and the loop editor.
- **The desktop entry and the windows now agree on their class.**
  - Before, the windows' class was `dspatch` and the entry's `StartupWMClass` was `DSpatch`. A dock that matches on that field could show the windows apart from the launcher, with a generic icon.
  - Now both are `dspatch`.
  - The entry's file name (`dspatch.desktop`), the app id and `~/.config/DSpatch` are unchanged, so pinned launchers and your data stay.
- **About DSpatch** shows the icon.
- **The start page** shows the icon small, above the DSpatch wordmark.

Functional icons for tools, status and agents are unchanged.

The icon comes from one original, `app/build/icon-source/dspatch-icon.webp`. All sizes are derived from it by `npm run icons`.

## Install or upgrade

Install `dspatch_0.1.25_amd64.deb` on Debian or Ubuntu x64:

```bash
sudo apt install ./dspatch_0.1.25_amd64.deb
```

Installing over an earlier version keeps `~/.config/DSpatch`. If your desktop still shows the old icon after the upgrade, log out and in again; some docks cache icons.

0.1.25 changes no host method, so its host contract is the one 0.1.15 to 0.1.24 share. A host that one of those versions started, and that a closed window left running, is kept. At start DSpatch offers **Restart host**. Press it so that the running host is this version's. Nothing in this release depends on the host, so the icon is right before the restart too.

A host started by 0.1.14 or earlier cannot serve this window. At start DSpatch asks **Stop it and continue** or **Quit DSpatch**.

`dspatch-host-0.1.25-<commit>-linux-x64.tar.gz`, `host-manifest.json` and `SHA256SUMS` are published with this release.

## Verification

Checked before publication; details are in DSP-204 and `docs/evaluations/dsp-204/`.

**The icon trial on Linux,** run under Xvfb with a window manager and a panel, on the build and on the `.deb` installed on a runner:
- the desktop entry, and every hicolor icon byte for byte;
- each window's class, which matches the entry's;
- each window's own 256-pixel icon, compared pixel for pixel with the original's derivation;
- the start page;
- About;
- the taskbar, the launcher and Alt+Tab, as screenshots.

**The sizes:** 16 to 256 pixels inspected on light and dark backgrounds.

**Windows:** the executable and the installer built on Windows carry the icon at 16–256 pixels. They are not published.

**Not established:**
- GNOME's and KDE's own docks;
- Wayland;
- Windows' taskbar and shortcuts of an installed DSpatch;
- distributions other than Ubuntu and Debian;
- arm64.

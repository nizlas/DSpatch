# DSpatch 0.1.22

A Linux-only pre-release in which Essentials is extremely short: about two natural sentences before *Show more* (DSP-199). No Windows installer or Windows host package is published; the Windows work (DSP-182) is still open.

## Essentials, about two sentences (DSP-199)

- **Niclas's decision.** Extreme brevity is a primary goal of Essentials. The part before *Show more* aims at about two natural sentences on what the step accomplishes and its central role in the flow. It must be correct but need not be comprehensive. Calls, flags, fields, mechanisms, conditions and failure paths can go behind *Show more*, which may deepen the picture but is no inventory of what was read. Two sentences is a guideline, not a quota, and nothing is clipped.
- **One definition in every path, instruction version 12.**
  - Essentials replaces the shared scope rule, the walk's transition rules and the *Show more* rule with its own, in walk preparation, the loop's writer, a profile switch, *New response* and the deepenings.
  - The loop writer reads the planner's brief as material to select from.
  - The loop reviewer judges the short part apart from *Show more* and does not ask for details back. The facts are still checked.
  - The reference `docs/CODE_WALK_UNDERSTANDING_AND_PROFILES.md` is version 1.3.
- **The visible block.** In a walk prepared in Essentials with this version, the Step panel shows the short part with no summary line above it, and *Why it matters* stays empty. Walks prepared earlier are shown as they were.
- **Standard and Teacher are unchanged.**

Walks and explanations saved by earlier versions are kept as they are and not regenerated; they carry the *earlier version of the instructions* notice.

## Install or upgrade

Install `dspatch_0.1.22_amd64.deb` on Debian or Ubuntu x64 (`sudo apt install ./dspatch_0.1.22_amd64.deb`). Installing over an earlier version keeps `~/.config/DSpatch`.

0.1.22 changes no host method, so its host contract is the one 0.1.15 to 0.1.21 share. A host that one of those versions started and that a closed window left running is kept: at start DSpatch offers **Restart host**; press it before preparing walks or switching profiles, since the host builds the instructions. A host that 0.1.14 or earlier started cannot serve this window: at start DSpatch asks **Stop it and continue** or **Quit DSpatch**.

`dspatch-host-0.1.22-<commit>-linux-x64.tar.gz`, `host-manifest.json` and `SHA256SUMS` are published with this release.

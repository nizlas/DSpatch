# DSpatch 1.0.4

An ordinary release for **Linux x64** and **Windows x64**, and the new latest release. It carries what the pre-releases 1.0.1 to 1.0.3 brought since 1.0.0, and two changes to code walks.

## Code walks

- **Pane widths follow the code (DSP-216).** With Wrap lines off, each code pane is as wide as the longest line it shows by default, capped by a new **Max width: [120] chars** field beside Wrap lines. Empty means no limit; the value is kept per computer and is disabled, not cleared, while lines wrap. Short code gives narrower panes, longer lines scroll sideways, and panes take their room in the map instead of being squeezed to the window. A width set by hand still wins.
- **A step about unchanged code points at its lines (DSP-217).** When the active step's place holds no added or removed line, its exact lines are framed and lightly tinted in amber. A place with any change keeps only the diff's marking. The pane opens with the place's lines in view.
- **A corrected walk reads as finished (DSP-217).** When the walk's writer rewrites a step after the reviewer's findings, it is told to write one finished explanation, with no notes about its own writing. An answer that still holds such notes is asked for again. If it still has them, the earlier text is kept, nothing is cut, and the step goes back to the reviewer's verdict as a finding, so it is reworked or delivered with an objection rather than shown as accepted. A step whose claim is withdrawn is judged again for whether it still belongs in the walk; texts that name a removed or renumbered step are rewritten; opened and walked marks follow a step's content to its new number.

## Working on a Windows computer from Linux (since 1.0.0)

- Connect to a Windows host over SSH works: the host package goes over SFTP on the same connection (1.0.1), and Cancel stops a Connect.
- Two scripts prepare a Windows computer as an SSH host: `dspatch-prepare-windows-host.ps1` and the Linux helper `dspatch-prepare-linux-client.sh` (1.0.2).
- *Help → Connect to a Windows Host over SSH…* opens on three steps; the helper prints one ready command that downloads this version's Windows script and checks its SHA-256 (1.0.3). The rest of the guide is behind links.

## Install

- **Linux (Debian/Ubuntu x64):** `dspatch_1.0.4_amd64.deb`. Check it against `SHA256SUMS` and install with `sudo apt install ./dspatch_1.0.4_amd64.deb`. It carries both host packages, so it can install a host on a Linux or a Windows computer.
- **Windows (x64):** `DSpatch-Setup-1.0.4.exe`, a per-user installer. It is not signed; see [INSTALL.md](../INSTALL.md#windows).
- After an upgrade, a host started by the earlier version keeps running; the window reads *Restart needed to finish updating*, and **Restart host** starts this version's host with the data kept. For a Windows host used from Linux, Connect installs this version's host there.

## Known limits

Tried by agents: targeted tests and the type check for DSP-216 and DSP-217, and both seen in this checkout's build with a synthetic walk, headless with an isolated profile.

Not yet tried:

- the new code-walk behaviour on a real screen, and a real model following the writer's and reviewer's new rules;
- the Windows script's system-changing path on any Windows computer, and the whole three-step flow from a new Linux computer;
- a work network with its own policies;
- a pane keeps up to about two more columns than Max width when it needs no vertical scrollbar;
- an existing walk whose step text holds an editing note from before this release is not corrected by it; such a walk has to be generated again.

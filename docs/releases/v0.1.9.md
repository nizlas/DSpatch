# DSpatch 0.1.9

## Code-walk stops and profile presentation

- Before/after references to the same code change are now one shared **code stop** in walk navigation (not two separate Old/New stops), while distinct code places still remain separate stops when the explanation changes focus.
- Step navigation, counters, next/previous and timeline highlighting follow that shared-stop model.
- Presentation profiles now share the same readable typography in Step/Discussion, so **Original**, **Essens** and **Pedagog** differ by explanation style, not by denser rendering.
- Essens has a tighter base explanation budget, with deeper detail behind *Show more*.
- A saved profile alternative can now be explicitly regenerated.

## Persistent profile choice and persistent window layout

- The selected explanation profile is now persisted with each walk and survives restart.
- The latest chosen profile is remembered as default for newly opened walks.
- When you navigate to a step that lacks the selected profile alternative, DSpatch can request it after navigation settles (no automatic generation just by reopening the app).
- Window layout is now persisted locally on the client: position, size, maximized state, and review panel placement (docked/floating) with panel geometry.
- Saved geometry is clamped back to visible screens when monitor setup/resolution/scaling changed.

## Linux download

Install `dspatch_0.1.9_amd64.deb` on Debian or Ubuntu x64. The matching Linux host archive, `host-manifest.json` and `SHA256SUMS` are published with this release.

# DSpatch 0.1.21

A Linux-only pre-release that tightens profile calibration checks in walk generation and the loop reviewer (DSP-197).

## Profile calibration enforcement (DSP-197)

- **Instruction version 11.** Presentation instructions now state explicitly that profile fit is judged in both directions: the first part can be rejected when it is too thin or too dense/verbose for the chosen profile.
- **Shared explanation task.** The short part is kept readable for the current reader; secondary detail should move behind *Show more* instead of crowding the first part.
- **Standard profile tuning.** Standard now says explicitly that the first part should stay compact enough for the mechanism to remain clear; side mechanics and extra examples belong after the marker unless they change the core understanding.
- **Loop reviewer criteria.** Reviewer prompts now include an explicit calibration check for the first part: enough on its own, but not crowded or verbose for that profile's reader.

These changes target Essentials, Standard and Teacher with profile-specific criteria. They do not add fixed word/sentence quotas and they do not change review facts, findings, decisions or coverage rules.

## Install or upgrade

Install `dspatch_0.1.21_amd64.deb` on Debian or Ubuntu x64:

```bash
sudo apt install ./dspatch_0.1.21_amd64.deb
```

Installing over an earlier version keeps `~/.config/DSpatch`.

# DSpatch 0.1.19

A Linux-only pre-release in which Essentials makes a selection of its own, also when you switch the reading profile on a walk (DSP-194, a follow-up of DSP-192). No Windows installer or Windows host package is published; the Windows work (DSP-182) is still open.

## Essentials (DSP-194)

- **What drove the detail.** Compared with Copilot on one locked walk plan: in the walk loop, the planner's brief for each step (written before the profile is known) was read as a list of what must be said; when switching profile on a walk, the answer format shared with review questions added content rules of its own (a risk in the first part, cause and effect with real names, what could not be read). Taking the walk's own Standard text away did not make Essentials select more, so that text is kept as material.
- **The change, instruction version 9.** The writer reads the brief as orientation written for every profile, and the profile decides which of its points the reader needs; a profile's explanation of a step (switching profile, *New response*) gets the form of the answer only; Essentials says what a mechanism achieves and what follows from it, not the operations that achieve it. Standard and Teacher are unchanged. The reference `docs/CODE_WALK_UNDERSTANDING_AND_PROFILES.md` is version 1.2.
- **What it gives, so far.** In the step where several mechanisms meet, Essentials now says what the deferral achieves and the order you take onward, with the operations behind *Show more*, written during the walk and as an alternative afterwards. In the simple step it is uneven: it can still restate the code or add the failure path's report. One provider, one example: your own reading decides.

Walks and explanations saved by earlier versions are kept as they are and not regenerated; the *earlier version of the instructions* notice on them is the one from 0.1.15. Everything of 0.1.18 stands: a delegated review is the agent's assessment until you accept it.

## Install or upgrade

Install `dspatch_0.1.19_amd64.deb` on Debian or Ubuntu x64 (`sudo apt install ./dspatch_0.1.19_amd64.deb`). Installing over an earlier version keeps `~/.config/DSpatch`.

0.1.19 changes no host method, so its host contract is the one 0.1.15 to 0.1.18 share. A host that one of those versions started and that a closed window left running is kept: at start DSpatch offers **Restart host**; press it before preparing walks or switching profiles, since the host builds the instructions. A host that 0.1.14 or earlier started cannot serve this window: at start DSpatch asks **Stop it and continue** or **Quit DSpatch**.

`dspatch-host-0.1.19-<commit>-linux-x64.tar.gz`, `host-manifest.json` and `SHA256SUMS` are published with this release.

## Verification

Checked before publication (details in DSP-194): type checks and the build; the prompt tests, the presentation group and the review group; the follow trial in real windows with the simulated provider, with a new stage for *New response* and going back to the saved explanation; the comparison with Copilot (`copilot-default`) on one locked plan and the profile switch through the real windows with Copilot, kept with their judgment in `docs/evaluations/dsp-194/`.

Not established: other providers and models at version 9 (Claude was not rerun), more than two steps of one example, Windows, other distributions than Ubuntu and Debian, and arm64.
